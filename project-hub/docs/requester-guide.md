# Requester guide

1. Click **New request** (or a type on the home page).
2. Answer five plain questions: what you need, what it should achieve, any details (optional), when you need it (or "I'm flexible"), attachments (optional). *Improve with AI* can tidy your wording — you review it first, and *Restore original* undoes it.
3. You get a reference like **REQ-1042**. That's a receipt, not an acceptance.
4. **My requests** shows each request's status in plain words, the expected date once the team commits to one, and your point of contact.
5. If the team needs something, the request shows **Waiting on you** — answer in the conversation.
6. When work is delivered you'll see the version, files/links, and **Approve** or **Request changes**.
